# Network transcription

Add explicit account-scoped network dictation to Agent, independently of spoken
replies. Preserve local and connected-provider choices. Capture stays on the
device until the user selects network dictation; changing accounts cannot inherit
that consent. Recording, cancellation and review must keep their existing owners.

The initial native replica uses pinned openai/whisper-small revision
973afd24965f72e36ca33b3055d56a652f456b4d, verified safetensors and processor files,
CUDA FP32, one slot, two CPU threads and an existing physical contributor's own
policy. A separately booked 2048 MiB native reservation is required. The private
qualification opens no listener and may use only its exact prepared reservation.
Serving requires a committed reservation and fresh source/session/activation proof.

Only canonical mono 16 kHz PCM WAV, at most 30 seconds, is accepted. The browser
converts recorded audio before upload; native inference accepts no media URL or
compressed decoder. Spanish and English are supported. Bind results to the audio
SHA256 and requested language. Silence or invalid results fail without settlement.

Use deployment-owned MYCELLIOS_NETWORK_TRANSCRIPTION_IDENTITIES and the existing
authenticated pinned-edge scheduler, never an HTTP placement override. Both the
saved connection and requested Mico must belong to the authenticated account and
Space. A failed paid request has no automatic replay or provider/funding fallback.
Raw audio is not appended to durable inference conversations.

Usage is the cl100k_base token count of recognized speech, with zero generated
text tokens. Bound the credit reservation by the maximum accepted transcript,
never by base64 bytes. Preserve signed execution receipts, physical contribution
evidence, balanced ledger entries, hold release and provider ownership transfers.

Qualification: focused native contract/qualification/economic/privacy and Python
audio tests, Agent isolation/dictation/audio/settings tests and types. Then six
private GPU samples, three normal coordinator qualification leases, real funded
Spanish/English requests, failed-input hold release and authenticated browser
dictation. Inspect actual debit, settled hold, provider transfer and zero ledger
sum. None of these proves execution split across two physical computers.

Publish only the integrated, built candidate with preserved overlays, an admission
barrier covering all coordinator callers, completed active requests, retained
containers and immutable artifact/health receipts. A worker-maintenance flag or
an empty jobs query alone does not establish that barrier.
