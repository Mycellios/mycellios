# Mycellios

<!-- impeccable:product-schema 1 -->

## Platform

Web. The marketing site uses the existing React/Vite application and shared production components in `landing/src/ui`.

## Product Purpose

Mycellios is an independent distributed inference runtime. Mycellios Agent is its separate conversation workspace. The network is the main subject of the landing; Agent must remain easy to open. Daniel confirmed this priority on 2026-10-25.

## Users

The site provides entry points for people using Agent, developers inspecting the API, and owners of compatible devices considering contribution. Hardware and model support must be taken from the current product, not inferred from the network illustration.

## Capabilities and Constraints

`docs/STATUS_AND_EVIDENCE.md` is the sole capability/evidence authority. Illustrations describe the network concept; they are not measurements or proof of multi-host operation. Do not invent customers, performance, payouts, or completed tasks.

## Brand Commitments

Preserve the Mycellios name, organic mark, mushroom/mycelium identity, Agent typography, warm paper and restrained moss palette. Primary controls remain flat and use the shared UI kit. Keep the current landing recoverable and available for comparison. Do not change the panel or Agent application as a side effect of this landing redesign.

For the current landing, follow the supplied Compute, Antseed and Rakazo references in composition and product presentation as well as palette. Daniel rejected the decorative assemblage direction; its earlier selection is historical, not current approval. Keep the network first and Agent easy to open.

## Evidence on Hand

Existing brand artwork and procedural mushroom, shared UI/Storybook components, public network routes and source code. The public Agent endpoint redirects anonymous visitors to sign-in; an authenticated workspace screenshot was not supplied for public use.
