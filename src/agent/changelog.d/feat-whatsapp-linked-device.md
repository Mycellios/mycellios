### Added

- Link your WhatsApp number to Mycellios Desktop with a QR code or a pairing code, and chat
  with your Mico from WhatsApp. Write to it in "Message yourself", allow the contacts and
  groups that may reach it, or use a dedicated number where new people receive a code that you
  approve in Mycellios.

### Self-host upgrade notes

- The WhatsApp linked-device connector stays off until the API runs with
  `MYCELLIOS_WHATSAPP_DEVICE_ENABLED=true`. Apply the database migrations first.
