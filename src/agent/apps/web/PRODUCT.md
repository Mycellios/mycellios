# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Mycellios users work with Micos and tools through web, PWA and Desktop. Apps serves
people who want a repeatable visual workflow instead of rewriting prompts.

## Product Purpose

Apps is an integrated catalog of versioned tools using the existing Mycellios
session. The first tool takes an idea through a reviewed video workflow.

## Operating Context

The catalog opens from the existing sidebar without replacing a chat or sending
its draft. A project retains its definition version, script revision and media.
Local and Cloud execution are distinct destinations; unavailable destinations
must say so. This first implementation runs on the Windows Desktop PC.

## Capabilities and Constraints

The v1 video studio uses six Spanish scenes, local Codex for structured scripts,
installed Windows speech voices and a trusted typographic MP4 compositor. Projects
are private to account/Space/device. Public listing, votes, cross-device sync,
Cloud execution, generated illustrations and social publishing are not connected.
No separate login, hidden paid provider or automatic destination fallback.

## Product Principles

- Fixed, versioned flows make shared tools predictable.
- Show actual state, errors and artifacts; never substitute a prompt for an output.
- Review media before rendering; edits invalidate earlier approvals.
- Preserve existing chats, drafts, consent and other collaborators' work.
