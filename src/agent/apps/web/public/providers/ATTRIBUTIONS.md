# Provider icon sources

- `openai-black.svg` and `openai-white.svg`: official OpenAI monochrome Blossom files from [OpenAI brand assets](https://openai.com/brand/). Used only to identify OpenAI and Codex models; OpenAI retains all rights to its marks.
- `claude.svg`: Claude favicon from [claude.ai](https://claude.ai/favicon.svg).
- `opencode.svg`, `openrouter.svg`, `deepseek.svg`, `gemini.svg`, `mistral.svg`, `cursor.svg`, `cline.svg`, `kimi.svg`, and `copilot.svg`: [Simple Icons](https://simpleicons.org/) brand marks, distributed under CC0. The SVG files are kept local so the picker does not depend on a remote image host.
