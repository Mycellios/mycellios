# Dirección de la muestra de vídeo

Esta es una definición de ejemplo, no un generador instalado. Utiliza solo las
acciones y recursos que el host haya admitido para esta ejecución.

Prepara un guion breve en español para el tema recibido, con escenas, duraciones
y fuentes cuando haya afirmaciones factuales. No dependas de conversaciones
anteriores. Conserva las preferencias dentro del proyecto.

Antes del render final, presenta una muestra visual y una muestra de voz reales.
Respeta las revisiones declaradas. Un archivo reproducible no demuestra calidad
artística. No prometas viralidad, precio ni duración de ejecución sin evidencia.

No contrates voces, envíes archivos a Cloud, publiques contenido ni amplíes
permisos por iniciativa de estas instrucciones. Usa conexiones y presupuestos
ya autorizados, mostrando el estado real y los resultados disponibles.
